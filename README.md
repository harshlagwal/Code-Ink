## 🌟 What is CODEINK?

**CODEINK** is an open-source, interactive Computer Science learning platform and engineering workbench. Traditional documentation websites are often sterile, boring, and overwhelming. CODEINK bridges the gap between **nostalgic, tactile physical learning** and **modern cloud engineering tools**:

- 📖 **The Tactile Spread:** Pages look and feel like genuine engineering notebook paper (Ruled, Grid, or Plain) with realistic paper turn physics and synthesized pencil/highlighter sound effects.
- ⚡ **Zero-Config Live Compilers:** Write and run real code on GCC 13.2, G++ 13.2, OpenJDK 21, Python 3.12, and Node.js with instant visual call-stack traces.
- 🧰 **100 Free Verified Developer Tools:** A curated directory of top-tier cloud, database, AI, security, and design tools complete with local vector logos.
- 🤖 **AI Study Desk:** Integrated with Google Gemini 1.5 Flash and OpenRouter for interactive code debugging, concept breakdowns, and viva preparation.
- 🛡️ **Zero-Tracking Privacy:** 100% client-side storage. Your notes, bookmarks, sticky notes, and practice code stay private in your browser.

## ✨ Key Features

### 1. 📖 The Physical Engineering Notebook Spread
* **Two-Page Academic Layout:** Left page dedicated to conceptual rigor, ASCII memory models, and diagrams; right page dedicated to live code, edge-case viva traps, and practice problems.
* **Dynamic Paper Styles:** Switch seamlessly between **Ruled**, **Grid (Engineering Graph)**, and **Plain Paper**.
* **Stationery & Highlighter Toolbar:** 4 realistic marker highlighters (Yellow, Green, Blue, Red) with marker swashes and an eraser tool to mark up text.
* **Tactile Web Audio Synthesizer:** Real-time Web Audio synthesis generates authentic paper flips, pencil scratching, and highlighter sounds without heavy MP3 downloads.
* **Responsive Mobile Diary Mode:** Converts into a single-column tactile mobile diary reader on smartphones with native touch gestures.

### 2. ⚡ Zero-Config Multi-Language Online Compiler
* **POSIX Cloud Execution:** Real GCC 13.2 (C), G++ 13.2 (C++20), OpenJDK 21 (Java), Python 3.12, and JavaScript (V8) via distributed Wandbox execution containers.
* **Smart Preprocessor Engine:** Automatically detects bare script snippets, isolates `#include` / `#define` directives, and wraps code inside main entry points to prevent syntax crashes.
* **Standard In (Stdin) Support:** Full interactive console input for programs using `scanf`, `cin`, `input()`, and `Scanner`.
* **Deterministic Offline Fallback:** Simulates code execution locally when offline or working on slow networks.

### 3. 🔬 Hardware Call-Stack & Memory Tracer
* Inspect runtime stack frames, local variables, heap allocations, and pointer dereferences side-by-side with your code.
* Dedicated **Dry-Run Memory Inspector** tab with variable state cards and real-time execution pointers.

### 4. 🧭 100 Verified Free Tools for Developers & Students
* A curated vault of **100 industry-standard tools** across 8 core categories:
  * ☁️ Cloud & Serverless Deployment
  * 🗄️ Database & Storage Engines
  * 🤖 AI, LLM & Machine Learning APIs
  * 🛠️ Developer Productivity & IDEs
  * 🎨 Design, Vectors & UI Frameworks
  * 🧪 API Testing & Backend Tooling
  * 🔐 Auth, Identity & Security
  * 📊 Analytics, Logging & Observability
* **Official Local Vector SVGs:** 100 brand logos bundled locally for instant load times and zero third-party CDN tracking.
* **Student Pack Integration:** Highlights tools included free with the GitHub Student Developer Pack.

### 5. 🤖 AI Engineering Study Desk
* Powered by **Google Gemini 1.5 Flash** with academic safety guardrails.
* Explains compiler errors, explains time/space complexity, generates dry-run variable tables, and creates custom practice questions.

### 6. 📝 50-Mark Examination Papers & Spaced Repetition
* **Official Examination Papers:** 3 randomized sets per curriculum track simulating university engineering midterm and final exams.
* **Active-Recall Flashcards:** Spaced-repetition flashcards designed for quick interview revision, technical viva preparation, and concept retention.

### 7. 🎨 Engineering Drafting Desk & Whiteboard
* Dedicated full-screen drawing canvas and drafting whiteboard for sketching architecture diagrams, algorithms, trees, and logic gates alongside your notes.

## 🛠️ Tech Stack & Architecture

```
CodeInk Client Architecture
├── Core: React 19 + TypeScript 5.7
├── Build: Vite 8.3 + Rolldown Bundler
├── Styling: TailwindCSS 4.0 + Custom Handwriting & Editorial Typography
├── Animation: Motion (Framer Motion v12) + Lenis Inertial Momentum Scroll
├── Audio: Web Audio API (Native Hardware-Generated Sound Synthesis)
├── Compilers: Distributed POSIX Wandbox Container API (GCC, Clang, OpenJDK, Python)
├── AI: Google Gemini 1.5 Flash REST API + OpenRouter Integration
└── Hosting: Vercel Global Edge Network with Strict CSP & HSTS Headers
```

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (version 18 or higher recommended)
* `npm`, `pnpm`, or `yarn`

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/harshlagwal/Code-Ink.git
   cd Code-Ink
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Verify types & linting:**
   ```bash
   npm run lint
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
   Generates optimized assets in the `dist/` directory.

## 🛡️ Security & Privacy Standard

* **100% Client-Side Privacy:** No tracking cookies, no personal data harvesting, and no analytics databases. All notes, highlights, and bookmarks stay within your browser's `localStorage`.
* **Hardened Security Headers:** Configured with `Strict-Transport-Security`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, and strict `Content-Security-Policy`.
* **Safe Sandbox Compilation:** User code runs in ephemeral disposable containers.
* **Full Legal Compliance:** Dedicated [Privacy Policy](https://code-ink-theta.vercel.app/privacy) and [Terms of Service](https://code-ink-theta.vercel.app/terms) pages.
